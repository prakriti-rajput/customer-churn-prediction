# Dataset folder

Place the IBM Telco Customer Churn CSV file in this folder.

1. Open <https://www.kaggle.com/datasets/blastchar/telco-customer-churn> (free Kaggle login needed).
2. Click **Download** and unzip the file.
3. Copy `WA_Fn-UseC_-Telco-Customer-Churn.csv` here.

The notebook accepts either of these file names:

- `WA_Fn-UseC_-Telco-Customer-Churn.csv` (Kaggle name)
- `Telco-Customer-Churn.csv`

If neither file is present, the notebook tries to download the IBM copy automatically and saves it here.
